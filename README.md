### Overview

Displays Vana'Diel Clock, Moon Phases, and Elemental Day Transistion day images with sound. 

- By default it uses the Arial font, but I've included a free ffxi style font called Cinzel that can be installed via the `Font - Readme folder`


* Commands: /vc or /vanaclock
  - /vc          - Toggles the Vana'diel clock on/off.
  - /vc help     - Lists available commands below.
  - /vc ui       - Shows Config UI.
  - /vc config   - Shows Config UI.
  - /vc save     - Save Clock & Moon position settings.

### Installation

* Download and unzip the correct version of VanaClock at https://github.com/Mr-Sithel/vanaclock/releases/
* Copy the `vanaclock` folder from inside of the `VanaClock-(X.X.X)` folder into your Ashita addons directory
* Addon example directory : `HorizonXI\Game\addons` or `PhoenixXI\addons`
* This was created for `Ashita (Interface v4.30)`
* You can load the addon by typing `/load addon vanaclock`.  It is recommended you add this line to the appropriate place in `scripts/default.txt` to auto load.
